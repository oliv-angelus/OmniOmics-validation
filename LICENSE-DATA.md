# License for data files

The `LICENSE` (MIT) in this repository's root covers scripts and configs. The
ground truth tables and result/comparison data under every `*/ground_truth/`
and `*/results/` folder are licensed [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/)
instead — the standard choice for a dataset/reproducibility-package release,
distinct from the code license.

Raw sequencing data is not included in this repository at all (see the main
`README.md`); only its own upstream license/terms apply, and it remains
governed by its original public source (SRA/ENA/GEO/vendor open-data), cited
per pipeline.
